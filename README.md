# Illustration Archive

> いいね（ブックマーク）した作品をローカルに保存するブラウザ拡張機能

作品の画像とメタデータを、ユーザーが選択したフォルダーへ保存します。独自の外部サーバーは使用しません。

## 主な機能

- 作品画像と `metadata.json` のローカル保存
- 任意のフォルダーや外付けストレージへの保存
- 作品の手動保存と、任意で有効にできる自動保存
- タイトル・作者・タグによる検索
- 画像の拡大表示、メタデータ表示、Google検索
- 複数作品の選択と一覧からの一括削除
- ライトモードとダークモード

## 動作環境

- Google ChromeなどのChromium系ブラウザ
- Manifest V3とFile System Access APIに対応した環境
- ログイン済みのpixivアカウント

Firefoxには現在対応していません。

## インストール

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions` を開く
3. 「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」を選択する
5. このリポジトリのフォルダーを指定する

## 使い方

1. 拡張機能のポップアップから「保存一覧を開く」を選択する
2. 初回のみ表示される利用上の注意を確認し、同意する
3. 「保存先」から画像を保存するフォルダーを指定する
4. 作品ページでポップアップを開き、「この作品をローカル保存」を選択する
5. 「保存一覧を開く」から保存した作品を閲覧する

> [!TIP]
> 保存一覧ページは、ブラウザでブックマークしておくとすぐに開けます。操作手順は保存一覧上部の「使い方」からいつでも再表示できます。

### 自動保存

自動保存の初期設定はオフです。有効にする場合は、保存一覧で「自動保存」をオンにし、表示される注意事項に同意してください。その後、作品をいいね（ブックマーク）すると選択済みのフォルダーへ保存されます。

保存に失敗した場合は、作品ページで拡張機能のポップアップを開き、手動保存を試してください。

## 保存されるデータ

作品ごとに次のようなフォルダーを作成します。

```text
選択した保存先/
└── 作品ID_タイトル/
    ├── metadata.json
    ├── p0.jpg
    └── p1.jpg
```

画像の拡張子と枚数は作品によって異なります。ブラウザ内には、保存一覧を表示するためのメタデータと保存先の設定を保持します。

同じ作品を再保存すると、同名ファイルを置き換えます。保存一覧から作品を削除しても、保存先フォルダー内の画像ファイルは削除されません。

## キーボードショートカット

| キー                   | 操作                         |
| ---------------------- | ---------------------------- |
| `/`                    | 検索ボックスへ移動           |
| `Cmd + A` / `Ctrl + A` | 表示中の作品をすべて選択     |
| `Esc`                  | 選択をすべて解除             |
| `Enter`                | フォーカス中の画像を拡大表示 |

## 使用する権限

- `storage`: 設定と保存一覧用メタデータの保持
- `scripting`: 作品ページからの情報取得
- `declarativeNetRequestWithHostAccess`: 作品画像を取得する際のリクエスト調整
- `https://www.pixiv.net/*`: 作品情報の取得
- `https://i.pximg.net/*`: 作品画像の取得

外部サーバーへのアップロードや共有リンクの作成は行いません。詳細は [プライバシーポリシー](PRIVACY.md)を参照してください。

## 現在の制限

- pixivのページ構造が変更されると、作品情報を取得できなくなる場合があります
- うごイラ、小説、外部転載元の探索には対応していません
- 保存容量の上限設定、自動削除、画像形式の変換には対応していません
- 保存先へのアクセス権限が失われた場合や外付けストレージを取り外した場合は、保存先の再選択が必要です
- ブラウザのプロファイルを削除すると保存一覧と設定は失われますが、保存済みの画像ファイルは残ります

## 開発

ビルド処理はありません。変更後、`chrome://extensions` で拡張機能を再読み込みしてください。

```text
assets/       アイコン
src/          HTML、CSS、JavaScript
manifest.json 拡張機能の設定
rules.json    画像取得時のリクエストルール
```
