# Illustration Archive

> いいね（ブックマーク）した作品をローカルフォルダーへ記録するブラウザ拡張機能

作品の画像とメタデータを、ユーザーが選択したフォルダーへ記録します。独自の外部サーバーは使用しません。

## 主な機能

- `metadata.json` を中心とした作品情報の記録
- オプションによる作品画像の記録
- 任意のフォルダーや外付けストレージへの記録
- 作品の手動記録と、任意で有効にできる自動記録
- タイトル・作者・タグによる検索
- 画像の拡大表示、メタデータ表示、Google検索
- 記録した元画像URLとファイル名を使った検索支援
- 複数作品の選択と一覧からの一括削除
- ライトモードとダークモード

## 動作環境

- Google ChromeなどのChromium系ブラウザ
- Manifest V3とFile System Access APIに対応した環境
- ログイン済みのpixivアカウント

Firefoxには現在対応していません。

## インストール

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions` を開く
3. 「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」を選択する
5. このリポジトリのフォルダーを指定する

## 使い方

1. 拡張機能のポップアップから「記録一覧を開く」を選択する
2. 初回のみ表示される利用上の注意を確認し、同意する
3. 画像を含める場合や、メタデータをファイルとして残す場合は「記録先」からフォルダーを指定する
4. 作品ページでポップアップを開き、「この作品を記録」を選択する
5. 「記録一覧を開く」から記録した作品を閲覧する

> [!TIP]
> 記録一覧ページは、ブラウザでブックマークしておくとすぐに開けます。操作手順は記録一覧上部の「使い方」からいつでも再表示できます。

### 自動記録

自動記録の初期設定はオフです。有効にする場合は、記録一覧で「自動記録」をオンにし、表示される注意事項に同意してください。その後、作品をいいね（ブックマーク）すると選択済みのフォルダーへ記録されます。

作品ページを閲覧しただけでは記録されません。自動記録は、いいね（ブックマーク）操作を行った時だけ実行されます。

メタデータのみの自動記録では、作品ページに埋め込まれた情報を使用します。ブックマーク状態の再確認や再試行のための追加通信は行いません。「画像を含める」がオンの場合のみ、画像の記録に必要な作品情報と画像を取得します。

記録に失敗した場合は、作品ページで拡張機能のポップアップを開き、手動記録を試してください。

### 画像の記録

初期設定ではメタデータのみをブラウザ内の記録一覧へ登録し、作品画像は取得しません。この場合、記録先フォルダーが未選択でも利用できます。画像も必要な場合は、記録先フォルダーを指定してから「画像を含める」をオンにし、表示される注意事項へ同意してください。この設定は以後の手動記録と自動記録に適用されます。

メタデータのみの場合も、記録時点の元画像URLとファイル名を手掛かりとして保持します。「元画像を探す」から、作品ID・タイトル・作者・ファイル名・元URLを使った検索リンクを利用できます。画像を直接取得したり、ローカルへ記録したりすることはありません。元画像が削除済みの場合など、再閲覧を保証するものではありません。

## 記録されるデータ

作品ごとに次のようなフォルダーを作成します。画像ファイルは「画像を含める」がオンの場合のみ記録されます。

```text
選択した記録先/
└── 作品ID_タイトル/
    ├── metadata.json
    ├── p0.jpg
    └── p1.jpg
```

画像の拡張子と枚数は作品によって異なります。ブラウザ内には、記録一覧を表示するためのメタデータと記録先の設定を保持します。

同じ作品を再記録すると、同名ファイルを置き換えます。記録一覧から作品を削除しても、記録先フォルダー内の画像ファイルは削除されません。

## キーボードショートカット

| キー                   | 操作                         |
| ---------------------- | ---------------------------- |
| `/`                    | 検索ボックスへ移動           |
| `Cmd + A` / `Ctrl + A` | 表示中の作品をすべて選択     |
| `Esc`                  | 選択をすべて解除             |
| `Enter`                | フォーカス中の画像を拡大表示 |

## 使用する権限

- `storage`: 設定と記録一覧用メタデータの保持
- `scripting`: 作品ページからの情報取得
- `declarativeNetRequestWithHostAccess`: 作品画像を取得する際のリクエスト調整
- `https://www.pixiv.net/*`: 作品情報の取得
- `https://i.pximg.net/*`: 作品画像の取得

外部サーバーへのアップロードや共有リンクの作成は行いません。詳細は [プライバシーポリシー](PRIVACY.md)を参照してください。

## 現在の制限

- pixivのページ構造が変更されると、作品情報を取得できなくなる場合があります
- うごイラ、小説、外部転載元の探索には対応していません
- 記録容量の上限設定、自動削除、画像形式の変換には対応していません
- 記録先へのアクセス権限が失われた場合や外付けストレージを取り外した場合は、記録先の再選択が必要です
- ブラウザのプロファイルを削除すると記録一覧と設定は失われますが、記録済みの画像ファイルは残ります

## 開発

ビルド処理はありません。変更後、`chrome://extensions` で拡張機能を再読み込みしてください。

```text
assets/       アイコン
src/          HTML、CSS、JavaScript
manifest.json 拡張機能の設定
rules.json    画像取得時のリクエストルール
```
