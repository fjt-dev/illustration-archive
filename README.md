# Illustration Archive

いいね（ブックマーク）したpixiv作品のメタデータと画像を、ユーザーが選択したローカルフォルダーへ保存するChrome系ブラウザ拡張です。独自サーバーは使用しません。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このディレクトリを指定する

## 使い方

1. 拡張機能のポップアップで自動保存をオンにし、注意事項へ同意する（初期設定はオフ）
2. ログイン済みのpixivで作品にいいね（ブックマーク）する
3. 作品のメタデータと画像が自動的にローカル保存される
4. 拡張機能の「保存一覧を開く」からオフライン画像を閲覧する

初回起動時は著作権などに関する「利用上の注意」が表示され、同意後に操作手順が表示されます。操作手順は保存一覧上部の「使い方」からいつでも再表示できます。

自動保存に失敗した場合は、拡張機能の「この作品をローカル保存」で手動保存できます。

保存一覧の「保存先を選択」からローカルフォルダーを指定してください。外付けHDD上のフォルダーも選択できます。画像本体と `metadata.json` は作品ごとのフォルダーへ保存され、ブラウザ内には一覧表示用のメタデータだけが残ります。ブラウザがフォルダー権限を失った場合や外付けHDDを取り外した場合は、保存先を選び直す必要があります。

同じ作品を再保存すると、保存先フォルダー内の同名ファイルを置き換えます。保存一覧の削除操作はブラウザ内の一覧データだけを削除し、外部フォルダーの画像は削除しません。

## 現時点の制限

- pixivのページ構造変更により抽出処理が動かなくなる可能性があります
- うごイラ、小説、外部転載元の探索には対応していません
- エクスポート、保存上限、自動削除は未実装です
- ブラウザのプロファイルを削除すると作品一覧と保存先設定は失われますが、外部フォルダーの画像は残ります
- 利用前にpixivの現行利用規約と適用法令を確認してください

## プライバシー方針

- 外部サーバーは使用しません
- ログイン情報、作品情報、画像を第三者へ送信しません
- 無断転載や共有リンクを作る機能はありません

詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## 公開パッケージ

公開用ZIPには `manifest.json`、`rules.json`、`src/` を含めます。Chromeが生成する `_metadata/`、開発用の `work/` と `outputs/` は含めません。
